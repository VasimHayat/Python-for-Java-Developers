Indentation, truthiness, and identity

Python syntax removes braces but makes whitespace and object identity semantically visible.

Blocks are indentation. Truthiness is protocol-driven: empty collections, zero, None, and False are falsey. Use == for value equality and is only for identity singletons such as None.

Java
String s = new String("x");
if (s.equals("x")) {
    System.out.println("value");
}
Python
s = "".join(["x"])
if s == "x":
    print("value")
if s is not None:
    print("bound")
Idiomatic Python
Python
items: list[str] = []
if not items:
    print("empty")

sentinel = object()
value = sentinel
print(value is sentinel)
Coming from Java: Unlearn using identity as a cheap equality test. Python may intern some objects, but that is not your contract.
Under the hood

Names are bindings to objects. Assignment never copies an object unless code explicitly creates a copy.

Imports execute modules

Importing a Python module runs its top-level code exactly once per interpreter process.

Java class loading can initialize static state, but Python makes the file execution model more obvious. Top-level code should define constants, functions, and classes. Put side effects behind main() or functions.

Java
public final class Config {
    static final int PORT = 8080;
}
Python
# config.py
PORT = 8080

def describe() -> str:
    return f"port={PORT}"
Idiomatic Python
Python
def main() -> None:
    print("only when executed as a script")

if __name__ == "__main__":
    main()
Coming from Java: Unlearn treating imports as declarations only. A slow database call at module import time hurts every importer.

Exercises

Add a main guard
Move print or network side effects under if __name__ == '__main__'.
Predict output
If module a imports b twice, b top-level code runs once because sys.modules caches it.
