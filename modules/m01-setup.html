Runtime, REPL, and project shape

Python is an interpreter-first runtime where the source file is the artifact you run.

A Java build produces bytecode and a classpath. Python usually runs source directly on CPython, with bytecode caches as an implementation detail. The REPL is not a toy; it is a normal design and debugging surface. Treat a Python project as an importable package plus small command entry points, not a pile of scripts.

Java
// Maven/Gradle compile first, then run a class.
public class App {
    public static void main(String[] args) {
        System.out.println("ready");
    }
}
Python
# app.py
def main() -> None:
    print("ready")

if __name__ == "__main__":
    main()
Idiomatic Python
Python
# Run from the project root:
# python -m app

def normalize(name: str) -> str:
    return " ".join(name.split()).title()

print(normalize("  ada   lovelace "))
Coming from Java: Unlearn the reflex that every executable needs a ceremony-heavy class. Python's unit of reuse is the module; the class earns its place.
Under the hood

CPython compiles source to bytecode before execution, but the .pyc cache is not a portability contract like JVM bytecode.

Virtual environments and dependency metadata

A venv is closer to a local toolchain plus dependency sandbox than to a Maven module.

Java developers expect the build tool to own dependency resolution. In Python, the interpreter environment matters too. Use a virtual environment per project, declare dependencies in pyproject.toml, and prefer python -m pip so pip targets the interpreter you mean.

Java
// build.gradle.kts
dependencies {
    implementation("org.postgresql:postgresql:42.7.4")
}
Python
# pyproject.toml
[project]
name = "service"
version = "0.1.0"
dependencies = ["psycopg[binary]>=3.2"]
Idiomatic Python
Python
# Shell commands:
# python -m venv .venv
# .venv\Scripts\python -m pip install -e .
# uv sync  # if the team standardizes on uv
Coming from Java: Unlearn global installs. If you would not add a random jar to JAVA_HOME/lib, do not pip install into your system Python.
