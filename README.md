# Python for Java Developers: Beginner to Expert

This is a no-build static course site. Open `index.html` directly in a browser to start. The site uses CDN-hosted Tailwind, Prism, and Google Fonts; all course pages, styling, navigation, progress tracking, search, copy buttons, and collapsible exercises live in local files under `assets/` and `modules/`. Assumption: third-party ecosystem examples such as FastAPI, pytest, and pandas include install notes but are presented as focused teaching snippets rather than vendored dependencies.
